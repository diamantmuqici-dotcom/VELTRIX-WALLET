**Your Money. Your Universe.** The first public release of VELTRIX Wallet, a premium, offline-friendly fintech **simulator** for Android and Windows.

> **Everything in VELTRIX is fictional.** Every balance, transfer, card, account and trade is simulated and labelled as such. The app never connects to a bank, card network, broker or payment provider, never asks for real credentials and cannot move real money.

## Install

### Android

1. Open the APK link above on your phone to download it.
2. Open the downloaded file. If Android asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**. If Play Protect warns about an unknown developer, choose **More details → Install anyway**.

From a computer instead: `adb install VELTRIX-Wallet-v1.0.0.apk`

### Windows

1. Download the `.exe`. If your browser warns that the file isn't commonly downloaded, choose **Keep** (in Edge: **⋯ → Keep → Show more → Keep anyway**).
2. Double-click it. It is a single portable file: no installer and no admin rights needed.
3. The file is not code-signed, so the first time you run it SmartScreen shows **"Windows protected your PC"**. Click **More info → Run anyway**.

The wallet opens in its own Edge/Chrome app window. The UI is compiled into the `.exe` and is served only on `127.0.0.1`, never to the network. Your simulated data is kept in `%LocalAppData%\VELTRIX Wallet`; to remove the app, delete the `.exe` and that folder.

## What's inside

- **Home**: balance card with show/hide and display currency, eight quick actions, account tiles and configurable sections (activity, income/spend, category donut, 30-day trend, bills, goals, contacts, watchlist).
- **Send · Request · Receive**: recipient → keypad amount → note → review with a **SIMULATED TRANSACTION** banner → result, plus a demo QR code with fictional data only.
- **Card studio**: 10 materials with patterns and accents, freeze/unfreeze, limits, per-card history, presentation mode and an Android home-screen widget. Every card carries a permanent **DEMO CARD** label and has no CVV.
- **Accounts and ledger**: wallet, checking, savings, FX balances and a simulated credit line; 11 entry types with search, filters, sorting, refunds and reversals.
- **FX converter**: 16 currencies with bundled demo rates and optional, opt-in indicative live rates.
- **Markets simulator**: FX, indices, stocks, metals and crypto with labelled demo prices, charts and a practice portfolio with P&L.
- **Analytics, planning and extras**: spending breakdowns and trends, goals, budgets, subscriptions, bill reminders, a decimal-exact calculator, CSV export, backup/restore, app lock, light/dark themes and six accents.

Your data stays on your device: no sign-up, no analytics, no trackers. The only network access is the optional FX-rate download.

## Known limitations

- **Not yet run on a physical phone or a real Windows PC.** Both builds pass the automated checks below, but on-device behaviour still needs a manual pass. Please [open an issue](https://github.com/diamantmuqici-dotcom/VELTRIX-WALLET/issues) if something doesn't work.
- **The APK uses a public development key.** That is fine for sideloading a simulator, but anyone can sign an APK with that key, so only install it from this page and check the checksum. It cannot go on Google Play as-is.
- **The `.exe` is unsigned**, hence the SmartScreen prompt above.
- **No automatic updates.** New versions will appear on the [Releases page](https://github.com/diamantmuqici-dotcom/VELTRIX-WALLET/releases). An Android update signed with the same key installs over this version and keeps your data.
